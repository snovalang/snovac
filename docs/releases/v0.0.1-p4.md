# Snovac 0.0.1-p4

## Compiler organization

- Continued grouping implementation by responsibility under `runtime/`, `runtime/value/`, `runtime/bytecode/`, `runtime/eval/`, and `builtin/`.
- Split SNBC serialization, bytecode expression emission, runtime value equality, AST evaluator equality, evaluator region/environment handling, and declaration lookup into focused modules.
- Updated the common source manifest and architecture guide to reflect module ownership and build integration.

## Memory and ownership

- Added ownership checks for compound assignment and calls through moved closures.
- Kept root evaluator bindings in a stable arena and allocated environment metadata with its owning environment.
- Preserved array buffer reclamation and iterative value graph traversal; added overflow checks to interpolation buffer growth.
- Documented design tradeoffs against Rust ownership and Swift ARC, including that AST evaluator regions containing escaping values remain until execution ends. This release does not claim complete borrow checking or general leak freedom.

## Validation

- `make -j2` succeeds with the repository warning flags.
- `git diff --check` passes.
- The test suite was not run for this release preparation.
